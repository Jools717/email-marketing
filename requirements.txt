# Instalador Automatizado

Para instalar todas las bibliotecas y dependencias de este proyecto, simplemente ejecuta el archivo:

> **setup.bat**

### ¿Qué hace este instalador?
1. **Verifica** que tengas Node.js instalado.
2. **Instala** las dependencias del Backend (Nodemailer, PG, etc.).
3. **Instala** las dependencias del Frontend (Next.js, Tailwind, etc.).
4. **Configura** los archivos `.env` y `.env.local` con valores por defecto para que puedas empezar rápido.

### Requisitos Manuales
Después de correr el instalador, asegúrate de:
- Tener una base de datos **PostgreSQL** corriendo.
- Editar los archivos `.env` con tus credenciales de base de datos y correo.

### Comandos de ejecución rápida
- **Frontend**: `cd frontend && npm run dev`
- **Backend**: `cd backend && npm run dev`
- **Importador**: `cd backend && npx ts-node scripts/import_inegi_csv.ts`
